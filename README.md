
# CodeAlpha Internship Tasks

Welcome to my CodeAlpha Internship Projects Repository.

This repository contains three completed projects
developed as part of the CodeAlpha Internship.

## Task 1: Language Translation Tool

A language translation application developed
using Python and Streamlit.

Features:
- Multiple language translation
- Automatic language detection
- Text-to-Speech
- Translation history
- Multiple translation engines

Technologies:
- Python
- Streamlit
- Deep Translator
- gTTS

## Task 2: FAQ Chatbot

A chatbot application designed to answer
frequently asked questions.

Features:
- Interactive chat interface
- FAQ-based answers
- Similarity score
- Confidence threshold
- Conversation management

Technologies:
- Python
- Streamlit
- JSON

## Task 4: Object Detection and Tracking

An object detection and tracking system
using YOLOv8 and Deep SORT.

Features:
- Real-time object detection
- Object tracking
- Webcam and video input
- Object identification

Technologies:
- Python
- YOLOv8
- OpenCV
- Deep SORT
- NumPy
